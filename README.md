# Сайт компании

Статический сайт: главная, каталог (разделы и карточки товаров), новости, точки продаж с картой, палитра цветов, форма «Стать партнёром», политика конфиденциальности. База данных и админка не нужны, сайт работает на любом хостинге.

## Как устроено

```
content/        ← всё, что вы меняете: тексты, товары, магазины, цвета
  site.js         название, логотип, телефон, почта, цвета оформления, меню, карта, отправка формы
  home.js         тексты главной: слайды, «О нас», «Сервис», «Стать партнёром»
  products.js     разделы каталога и товары с характеристиками
  news.js         новости
  stores.js       точки продаж
  palette.js      палитра цветов
  privacy.js      политика конфиденциальности (заготовка!)
assets/         стили, скрипты, картинки
build.js        собирает сайт из content/ в папку dist/
serve.js        локальный просмотр
dist/           готовый сайт — его и загружаете на хостинг
```

В любом тексте можно писать `{brand}`, и на это место подставится название компании из `site.js`.

## Собрать и посмотреть

Нужен [Node.js](https://nodejs.org) версии 18 или новее. Больше ничего устанавливать не нужно.

```
node build.js      # собрать сайт в dist/
node serve.js      # открыть http://localhost:8080
```

Или одной командой: `npm start`.

После каждой правки в `content/` снова запустите `node build.js`.

## Что заменить перед запуском

- [ ] `site.js` → `brand`: название компании.
- [ ] `site.js` → `logo`: положите файл логотипа в `assets/img/` и укажите путь. Для тёмного подвала можно добавить светлую версию в `logoLight`.
- [ ] `site.js`: телефон, почта, Instagram, `url` (адрес сайта).
- [ ] `site.js` → `colors.accent`: ваш фирменный цвет.
- [ ] Фото. Сейчас вместо них нарисованные заглушки. Положите свои фото в `assets/img/` и укажите пути:
  - `home.js`: `hero.image`, `about.image`, `service.image`, `partner.image`;
  - `products.js`: `images: ['assets/img/products/имя.jpg']` у товара. Можно несколько, тогда появится галерея. Пока фото нет, рисуется банка с названием;
  - `news.js`: `image` у новости.
- [ ] `products.js`: ваши товары и реальные характеристики. Сейчас там примеры. PDF-документы (TDS, паспорта безопасности) положите в `assets/docs/` и укажите в `docs`.
- [ ] `stores.js`: ваши точки продаж.
- [ ] `privacy.js`: настоящая политика конфиденциальности вашей компании.
- [ ] Форма заявок и карта (ниже).

## Заявки с формы

Без настройки форма честно пишет, что не подключена. Варианты:

1. **Formspree** (бесплатно до 50 заявок в месяц, письма на почту). Зарегистрируйтесь на formspree.io, создайте форму и вставьте адрес в `site.js`:
   `form: { endpoint: 'https://formspree.io/f/xxxxxxx' }`
2. **Web3Forms** (бесплатно, письма на почту). Получите ключ на web3forms.com:
   `form: { endpoint: 'https://api.web3forms.com/submit', hidden: { access_key: 'ваш-ключ' } }`
3. **WhatsApp**: заявка откроется в WhatsApp с готовым текстом:
   `form: { whatsapp: '77000000000' }`

## Карта точек продаж

Откройте [конструктор Яндекс Карт](https://yandex.ru/map-constructor/), поставьте метки магазинов и нажмите «Получить код» → iframe. Скопируйте адрес из `src="..."` в `site.js` → `mapEmbed`.

## Публикация

Загрузите **содержимое папки `dist/`** на хостинг:

- **Netlify Drop** (app.netlify.com/drop): перетащите папку `dist` в окно браузера, и сайт заработает через минуту. Потом можно подключить свой домен.
- **Cloudflare Pages** или **GitHub Pages**: бесплатно, с собственным доменом.
- **Обычный хостинг** (например, казахстанский): загрузите файлы из `dist/` в корень сайта по FTP или через панель управления.

Если сайт открывается не с корня домена, а из подпапки, всё тоже будет работать: ссылки относительные.
